## Theme 001：佛教文庫｜DHARMA LIBRARY

### 宿主判定
不是「佛教元素裝飾」，而是寄生於華文佛教流通處／寺院結緣書／經典白話講記的完整出版語法：莊重、低作者姿態、經文權威高於作者、低價或免費流通、正文密、圖片克制、前置頁具有題名／經名／流通資訊／勸讀性文字。第一階段必須可信到可以被誤認為真正的佛教結緣出版物。

### 污染機制
污染不靠故意醜化佛教視覺，而靠宿主語法自身承載《剛吃飽》的作者性事故：經典權威、AI 共著、作者自薦、自我取消、免費流通、反原創聲明同時存在。作者自薦被寄生為「讚偈／序讚／流通語／跋語」等宿主原有元件；讀者先接受其形式，再發現內容正在破壞形式承諾。只有看起來像佛教書而內容搞笑不算通過；污染必須使「誰有資格解經、什麼算恭敬、什麼算作者、什麼算知識」變得不穩。

## 18 類規格

1. 書體／外殼：110×190mm 窄幅；平裝可裸背膠裝；封面以經名式層級處理《剛吃飽》，不做潮流插畫主視覺。
2. 前置頁與出版資訊：假書名頁／經名頁／文憑工廠出版資訊／流通說明均納入宿主語法；粗糙圓章保留，不清稿。
3. 整體版型：大留白與密正文交替；章首頁克制；不用網站卡片感。
4. 字體：繁中明體為正文主體；標題可宋／明體；避免把佛教感簡化為書法字。
5. 正文頁：正文來源零修改；窄欄、適合長讀；原文→白話→注釋的結構可由版面層級區分但不改文本。
6. 章節：22 單元完整保留；章號可寄生為「分／品／講」的視覺層級，但不得竄改正文正式名稱。
7. 圖像：低頻；允許佛像、經卷、寺院印刷物式黑白圖、既有正文圖；不得滿頁裝飾佛教符號。
8. 圖文關係：圖像像講記插圖／圖版／經文旁證，不像雜誌 hero image；既有 figure fallback 機制只作回歸，不重寫。
9. 特殊頁與元件：作者自薦可變成「讚」「跋」「流通偈」「編校記」；文憑工廠標語可寄生為流通頁格言。
10. 色彩：紙本以黑＋紙色為基準；可有單一低成本專色，但不是必要條件。
11. 紙材與實體質感：內頁米白／道林或輕型紙；封面非亮膜優先；允許廉價結緣書的觸感。
12. 裝訂結構：低成本膠裝優先；頁數不足時騎馬釘測試版可接受；不以精裝製造虛假高級感。
13. 低成本生產：黑白內頁、單色或雙色封面、標準紙；優先可小量 POD。
14. 莆田加強版：若做，不是加金加亮，而是把寺院流通品語法推至過度完整：燙金經名、紅章、護封／函套等；用過度恭敬承載不恭敬內容。
15. 電子版：EPUB/PDF 保留窄幅節奏但不硬鎖紙張；作者自薦依下載規則抽取；固定句不可漏。
16. Theme 辨識規則：拿掉《剛吃飽》文字後，仍應能從前置頁、字級、版心、流通頁、章法判定為佛教流通出版物；若只能靠蓮花／佛像辨識，FAIL。
17. Theme 禁區：禁止禪風咖啡店、New Age、日式極簡、金色豪華佛學、單純 CSS 換皮；禁止把所有作者自薦塞成固定一頁。
18. 測試頁與驗收：至少驗封面／假書名頁／出版頁／章首頁／長正文／圖文頁／作者自薦寄生頁／封底。寄生與污染分開打分，各自未達 PASS 不得進下一 Theme。
