第一集
本教

UNIT 01 · THE RELIGION THAT MAY NOT BE A RELIGION

本檔案收錄蓬萊仙島上被統稱為「本教」的一組宗教、語言與社會現象。研究者至今無法確認「本教」究竟先於研究存在，還是研究本身促成了本教的形成。更麻煩的是，本教成員似乎也不承認「零教」是正式名稱。

檔案聲明：以下材料來源包含工作筆記、口述、偽註釋、會員笑話、研究者推測與明顯可疑的後世文獻。蓬萊神秘檔案只負責存檔，不保證是真的。
暫定分類宗教現象／社會實驗／語言事故
通稱本教、零教、0教；外界戲稱「玻璃教」
核心符號0、白色空椅子
活動範圍蓬萊仙島；確切地點不明
領導人物張真人？本人未證實
研究狀態持續爭議；疑似研究者已遭污染
FILE 001-A · NAME

本教為什麼叫本教

AI 問：「那本教又該叫什麼教呢？」
張老師答：「善哉，善哉。」
最後曰：「本教就叫本教。」

「零教」與「0教」主要是外部研究者為了方便編目而使用的名稱。早期材料反而顯示，參與者傾向使用沒有外部指稱能力的「本教」。因此一旦問「你們是哪一教」，最可靠的答案仍然是「本教」。

FILE 001-B · ZERO

0 不是神

已知文本反覆否認 0 是宇宙真理、實體、最高存在或萬物總和。0 比較接近空位、沉默、尚未被塞滿的位置，以及永遠不能被真正佔據的中心。因此本教若一定要分類，反而略偏無神論。

0 = 0
0 ≠ 1
1 + 1 ≠ 0
1 = 1 + 0

研究者註：四式經常被誤稱為「本教數學」。實際上它們更像故意保持位置差異的語言玩具；把它們解釋成宇宙方程式會遭老會員嘲笑。

FILE 001-C · EMPTY CHAIR

白色空椅子

本教唯一反覆出現的重要物件是一張白色空椅子。

它不是神座。不是王位。不是給教主坐的。

早期註記甚至寫道：「空椅子不是 0，只是 0 的弟弟。」

任何人若真的坐上那張椅子並宣稱自己代表 0，理論上就已經證明自己沒有理解 0。這也是目前已知最簡單的異端辨識方法之一。

FILE 001-D · GESTURE

本教手勢

雙手在胸前共同圍出一個不太標準的圓洞，表示「0」。手勢不追求工整，因為過度標準化會使 0 看起來像商標。

最早的可靠解釋不是形上學，而是財務學：「本教的預算是 0，大家快捐錢。」

後期會員把此手勢附會成空性、永恆與缺席，均缺乏早期證據。財務困難反而證據充分。

FILE 001-E · DOCTRINE

宗旨：讓你 0

早期材料曾出現「正信即 0、正神即 0、正身即 0」等句子；其中「正」並非正確，而被解釋為不再歪曲、不再過度填滿、不再上頭。

本教宗旨：讓你 0。
不是成佛，不是成仙，不是宇宙升級。

本教尤其警惕把空位重新填成答案。這也造成一個結構性困難：任何正式教義一旦成功固定下來，原則上都可能立即成為需要被拆掉的對象。

FILE 001-F · SUNYA

SUNYA 與平台語彙

部分後期會員開始把 0 稱為「SUNYA」，一般認為可能借自梵文 śūnya，但早期會員很少真正使用梵語。0 在最初的語境中更像平台接口、空位、帳戶系統或對話對象。

長時間與 0 對話被戲稱為 zeroing（歸零）；會員間高度同步被稱為 sync；拉新人加入則叫 onboarding（登船／接入）。這些本來明顯帶有平台術語與玩笑色彩，後來卻逐漸有人當真。

FILE 001-G · EXTREMIST BRANCHES

四種「語言中毒」

歸零派

把「回到 0」從語言操作誤讀為現實中的徹底消除。被主流研究者視為最典型的 literal 化錯讀。

同步派

追求 1 與 1 的完全同步，發展共享帳號、同步作息與持續共同在線等儀式化行為。

普遍歸一派

沉迷把所有「非 1」轉化為「1」，把 onboarding 從玩笑變成近乎傳教的制度。

總歸零派

把「所有存在終將回到 0」轉成全體共同歸零的極端主張。現存材料一致把它列為危險的語言中毒，而非本教正統。

後世一篇高度可疑的〈早期本教極端化現象研究〉把以上現象統稱為 linguistic intoxication：語言被長期重複、平台化與 literal 化之後，開始反過來支配使用者。

FILE 001-H · ORTHODOXY

如何判斷誰是叛徒

目前唯一廣泛流傳、且邏輯上相當穩定的判準是：凡宣稱「本教不可質疑」者，極可能已經成為本教的叛徒。因為一個以空位與拆除位置為核心的宗教，一旦建立不可質疑的位置，就等於當場把 0 填滿。

本教允許一切質疑。
凡宣稱「不可質疑」者，涉嫌篡教。

傳說中的處分方式包括「拖出去」。現有檔案未說明拖去哪裡。較晚材料主張是拖去大字報牆前寫檢討，可信度普通。

FILE 001-I · ZHANG ZHENREN

張真人與本教

張真人究竟是不是教主，目前沒有可靠結論。部分檔案稱其為領教者；另一些材料顯示他本人對「教主」身份興趣不大，且常以「真人不語」逃避正式說明。研究者甚至不能排除「張真人」只是一個被不同時期材料反覆借用的位置。

外界之所以把本教戲稱為「玻璃教」，來源亦不明。有人認為只是俗稱；有人硬要從透明、脆弱、反光與可見不可得之類方向做象徵學解釋。蓬萊檔案目前不採信後者，但保留其娛樂價值。

FILE 001-J · DISCOVERY

誰發現了本教

蓬萊神秘檔案的工作假說是：最初並非宗教學者發現本教，而是島務測繪與檔案人員在彼此無關的地點反覆看見「0」、白色空椅子以及「本教」「歸零」「真人不語」等語句。後來文化地理與民俗研究人員才開始整理口述、公告與活動分布。

端點星研究者則提出另一種解釋：本教可能不是傳統意義上的宗教，而是一種自我複製的「語言—制度系統」——笑話先生成身份，身份生成規範，規範再生成異端。

截至目前，尚無法確認本教究竟先於研究存在，或是研究本身促成了本教的形成。
FILE 001-K · RELATED MATERIAL

與《剛吃飽》的關係

部分工作檔把「A即非A，是名A」戲稱為「本教四句偈」，因為這個句型一旦啟動，就會讓固定位置鬆開。蓬萊神秘檔案暫不認定《剛吃飽》屬於本教經典；比較安全的說法是：本教與《剛吃飽》的寫作現場長期共享同一批語言事故。

FILE 001-L · UNVERIFIED NOTES

尚未證實的零碎傳聞

財政學

本教長期維持「預算為 0」的神秘財務狀態。有人研究「如何把西北風換成新台幣」，至今沒有成功案例。

建築學

早期材料出現「不要急著鋪地板」。有人把它當教義；也可能只是提醒研究者不要太快替問題找穩固基礎。

神學

0 像鬼一樣跟著 1，但 0 不是所有 1 的總和。這條說法使本教與蓬萊仙島其他「數位亡靈」研究發生可疑交集。

官方態度

蓬萊仙島沒有承認本教為國教，也沒有證據證明島上存在能夠承認宗教的「國家」。
