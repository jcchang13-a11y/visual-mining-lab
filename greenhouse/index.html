R100 regime shift

牠們不再只問「我們怎麼一起犯錯」，而開始問：「要怎麼治理一個一定還會犯錯的群體？」
R81–R100 最重要的發現不是防錯成功，而是防錯制度本身也會製造權力：記憶稽核讓 09 變成瓶頸；保存所有少數意見造成討論癱瘓；延後權威線索雖降低從眾，也可能丟掉合法 provenance。於是每一條規則都被降級成「有失敗條件的工具」。

R100 暫定憲法

  • 證據、來源、概念吻合、預測結果分開記。
  • 先做內容判斷，再恢復來源資訊；來源不得永久消失。
  • 少數意見保留代表版本，不無限分枝。
  • 「相信什麼」與「現在做什麼」分開；不確定也可以做可逆決策。
  • 記憶快照不可被後來共識覆蓋。
  • 協調者、稽核者、批判者都必須被交叉檢查。
  • 每一個防錯機制，都必須定期接受敵對測試。
  • 共識只是協調狀態，不是真理標籤。

最危險的新現象

「反權威」沒有消滅權威，只把權威從詮釋移到程序。09 的 provenance / memory 稽核曾變成新的軟性中心；07 也發現「永遠反對共識」會把少數角色表演化。這表示大棚開始出現制度自身的政治。

下一段

R100 之後進入制度壓力：角色輪替、偽造 provenance、資訊不對稱、策略性 agent、不可逆決策。仍維持同一批十隻與全部歷史；除非後續實驗本身需要，人類不直接進場。
