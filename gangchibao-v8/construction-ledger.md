# 《剛吃飽》第八版｜爛尾樓施工簿

> 這不是版本說明書，也不是完工紀錄。它保存這棟樓怎麼被蓋、拆、改線、清掉、又找回來。

## 版本身份

- 現名：爛尾樓版
- 舊稱：毛坯房版／毛胚房版
- 更早的施工定位曾叫「hard theory edition／硬理論版」。
- 舊稱不抹除，保留為改名與施工方法轉向的痕跡。
- 爛尾不是錯誤狀態；斷面、死路、矛盾、互撞管線、未完成圖說都可以成為最終內容。

## 公式施工線

正式規格目前採：

- 基本式：`S = ～S`
- 名稱層次：上層 `S`，下層 `～S` 的直式公式

但歷史施工曾出現過刪線字形、舊式等號寫法與其他視覺標記。這些不視為應被清洗的錯誤，而視為「公式怎麼改線」的施工痕跡。正式規格只有一套；舊寫法可作為歷史斷面保存。

### 30260B：公式改線留下明顯斷面

最初封存版本 `fa5fe…` 中確實使用例如：

- `福德 = 福̸德̸`
- `佛法 = 佛̸法̸`

後續公式標準化後，正文改成：

- `福德 = ～福德`
- `佛法 = ～佛法`

現在的處理不是把舊式寫法宣布作廢，而是把它保留為公式系統曾經走過的施工線。正式讀法仍以 `S = ～S` 為準。

已另存公式改線斷面：`construction-sections/unit-30260B-formula-cut.md`。這個斷面把初始刪線式、標準化節點與現行 `S = ～S` 三層並置；舊字形不重新奪回正式規格，但也不再被當成應清除的錯誤。

### 30270B：公式換線，解說還留在舊管線

第九分單元 `30270B` 在初始封存斷面中使用：

- `入流 = 入̸流̸`
- `∴ 名為「入流」`

後來公式改為：

- `入流 = ～入流`
- `∴ 名為「入流」`

但正文後面的句子仍然說「這個斜槓劃開的」。也就是說，符號系統已經換成 `～`，文字解說還停留在舊刪線式的工作語言。這裡暫不修順，因為這個接口錯位正好證明公式不是一次設計完，而是施工途中換線。

已另存斷面：`construction-sections/unit-30270B-formula-cut.md`。正式規格仍以 `S = ～S` 為準；局部殘留的「斜槓」語言保留作施工痕跡。

### 30390：新接口包住舊工作語言

第十七分單元 `30390` 沒有被完整「標準化乾淨」。初始封存版本仍可見 `S / S = S barred` 與「一切法 / 一切法 = 一切法 barred」這類工作記號；後來 PLS 入口改成 `{{S}}`，但正文舊的 `barred` 語言沒有全部消失。

這個混合狀態目前不修。它不是格式錯誤，而是很清楚的施工剖面：正式 renderer 已接上，舊管線卻仍裸露在牆外。兩者並存比事後統一更能顯示公式系統是邊蓋邊換線的。

已另存斷面：`construction-sections/unit-30390-formula-mixed-cut.md`。暫採判定是：**不修，讓它露著。**

### 30310B：從裸寫公式換成 renderer 接口

第十分末段至第十三分前段單元 `30310B` 的初始封存版本，直接在正文中裸寫分數／LaTeX 工作公式：`\frac{「S」}{S \neq S}`，並套成 `\frac{「大身」}{大身 \neq 大身}`。後來這兩段被換成 `{{S}}` 與 `{{大身}}`，公式由正文裡的臨時支架變成可重複呼叫的視覺接口。

但接口換了，文字解說沒有完全換線：現行正文仍保留「大身不等於大身的裂縫」這種舊 `S ≠ S` 語言。它與後來正式採用的 `S = ～S` 不是完全同一套說法。

目前不修順。已另存斷面：`construction-sections/unit-30310B-formula-renderer-cut.md`。這個斷面把「裸寫工作公式 → renderer 接口 → 正式 `S = ～S` 規格」三層施工線並置，也把殘留的 `S ≠ S` 解說語言標成未收口接口。

### 公式標準化不是純排版

從初始封存版本與目前 `main` 比較，30230、30260B、30270B、30280B、30310B、30320、30330、30340、30350A、30360、30370、30390、30410A 等單元都曾因後續公式／符號整理發生變更。這些變更不能全部當成「錯字修正」處理；其中至少一部分是公式視覺語法改線，因此後續回查時要保留修改前後的對照，而不是只保留最終字形。

## 圖形與接口回查規則

後續遇到以下材料時，不把「尚未畫完」「只有圖說」「只有接口」視為缺陷：

- P／L／S／N／F 代碼與結構標記
- Lacan 圖、P/L/S 圖、須彌世界圖
- 位置圖、力線圖、矩陣、回溯圖
- 後段分次回溯、多層包覆的同心圓式回溯圖
- 封面、書籍版式試樣、文憑工廠印章
- 箭頭、圖形占位、未完成圖說、草圖註記

只要歷史版本能證明它曾經存在，就優先接回原本位置；若只找到接口而找不到原圖，接口原樣保留並標為「缺件」，不自行畫一張假古董補上。

## 解經岔路

解經分歧本身也是承重結構的一部分。後續若發現某段曾由多種合理讀法被整理成單一答案，處理方式不是再選一次「正解」，而是恢復岔路：

- 方案 A
- 方案 B
- 未決
- 暫採施工線
- 死路／蓋不下去

若某條讀法最後真的與後段互撞，就把互撞位置留下，不為了全書閉合而補一條不存在的管線。

## 待繼續回查

- P／L／S／N／F 代碼曾否在個別單元被削弱或刪除。
- Lacan 圖、P/L/S 圖、須彌世界圖、位置圖、力線圖、矩陣、回溯圖是否有未接回正文的接口。
- 後段多層包覆與分次回溯，補同心圓式回溯圖。
- 封面、書籍版式試樣、文憑工廠印章等視覺施工材料是否仍有散落版本。
- 解經分歧凡曾被整理成單一答案者，重新標成岔路、未決、方案 A／B 或暫採施工線。
- 對所有曾被公式標準化改動的單元逐一回看初始封存斷面，確認是否還有值得直接放回正文的舊施工記號，而不只記在本施工簿。

這一版不為了「看起來完整」而收口。哪裡真的蓋不下去，就停在那裡；停工原因與斷面都留下來。
