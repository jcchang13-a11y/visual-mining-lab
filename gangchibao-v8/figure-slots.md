## reader 接線方式

- `reader-core.html`：保存 2026-09-06 接圖前的完整 reader 原檔，不重寫其經文入口與既有 renderer。
- `reader.html`：只作很薄的施工殼，載入 `reader-core.html` 後再掛上 `original-figures.js`。
- `original-figures.js`：只對 `30310B`、`30340`、`30390` 三個已核定 anchor 插入使用者原圖；不改正文文字。
- `reading-layers.css`：新增 `.existing-figure`／`.original-figure` 共用閱讀框架，只控制最大尺寸、置中與 caption，不處理原圖內容。

## 接回時的硬規則

1. 只接受使用者原始圖或可由 Git 歷史確認的原始圖。
2. 不自行重畫、不矢量化、不補線、不校正歪斜、不統一字體。
3. 原圖一旦找到，先核對 placement，再把 slot 換成原圖引用；slot 的缺件階段保留在 Git 歷史作施工史。
4. 若同一原圖存在兩個以上同樣合理的正文位置，維持未決，不替作者裁決。
5. 2026-09-06 三張正文原圖與文憑工廠出版印章已由使用者重新提供 Direct link；「使用者未提供原圖」不再是缺件理由。
