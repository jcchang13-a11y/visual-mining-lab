# 30260B｜公式改線施工斷面

這個檔案不是把舊公式恢復成現行正文規格，而是把「舊寫法 → 標準化 → 現行規格」三層並排保存，避免後續再把施工史誤認成錯字史。

## 斷面 A｜初始封存

基準節點：`fa5fe86379f3ef74934b4160f8fd2f0f68e44174`

在第八版最初封存的 30260B 中，公式曾以刪線字形施工，例如：

- `福德 = 福̸德̸`
- `佛法 = 佛̸法̸`

這些字形現在不再作為正式規格，但它們證明公式系統一開始並不是直接長成 `S = ～S`。刪線不是裝飾，而是早期試圖把「即非」做成視覺動作的施工方法。

## 斷面 B｜標準化改線

關聯節點：

- `77df647e85a1e3c17148e3984adcd83104f91a73`：加入直式公式 glyph renderer。
- `f0e4b599c2a17d9f2ac3f8f1ec4c8ac04775c29c`：`Standardize V8 formula rendering`。

標準化後，正文中的同類公式被改為：

- `福德 = ～福德`
- `佛法 = ～佛法`

這裡發生的不是單純「修正錯誤」，而是公式視覺語法換軌：從「在 S 本身上劃掉」改成「把 ～S 作為另一個位置明確寫出來」。

## 斷面 C｜現行正式規格

現行正式規格仍是：

`S = ～S`

名稱層次則使用直式公式：上層 `S`，下層 `～S`。

但本斷面保留舊刪線形式，因為如果只留下現在的規格，讀者會誤以為這套公式從一開始就已經完成。實際上它曾經試過另一種身體：先直接在字上動刀，後來才改成把否定位置外置。

## 不收口

這兩種形式不必被重新統一成一個「正確美術版本」。目前只判定：

- 正式使用：`S = ～S`
- 歷史施工：刪線式 `S = S̸`
- 兩者關係：改線，不是單純勘誤

如果後面回查其他單元又找到第三種寫法，就再加第三層，不回頭把前兩層抹掉。
