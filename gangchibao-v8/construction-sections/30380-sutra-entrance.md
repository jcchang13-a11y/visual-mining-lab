# 30380｜本單元涉及經文｜施工入口

[[SUTRA: 本單元涉及經文｜能淨業障分第十六]]

【能淨業障分第十六】

「復次，須菩提！善男子、善女人，受持讀誦此經，若為人輕賤，是人先世罪業，應墮惡道，以今世人輕賤故，先世罪業即為消滅，當得阿耨多羅三藐三菩提。」

「須菩提！我念過去無量阿僧祇劫，於然燈佛前，得值八百四千萬億那由他諸佛，悉皆供養承事，無空過者；若復有人，於後末世，能受持讀誦此經，所得功德，於我所供養諸佛功德，百分不及一，千萬億分乃至算數譬喻所不能及。」

「須菩提！若善男子、善女人，於後末世，有受持讀誦此經，所得功德，我若具說者，或有人聞，心即狂亂，狐疑不信。須菩提！當知是經義不可思議，果報亦不可思議。」

[[/SUTRA]]

## placement note

此入口依 `unit-30380.md` 現有施工線鎖定：單元從第十六分第一句「受持讀誦此經，若為人輕賤」開始，正文接著持續處理先世罪業、惡道、今世消業、然燈佛之前供養無數諸佛、百分不及一，以及最後「是經義不可思議，果報亦不可思議」。因此本單元直接採完整第十六分，不向前重收第十五分；正文裡對「其福勝彼」的回接只視為前一分的論證接口，不擴張本單元經文入口範圍。

原有正文內三段經文重複引用、對「百分不及一」的兩種讀法與暫採施工線全部保留，不因建立入口而整理或裁決。
