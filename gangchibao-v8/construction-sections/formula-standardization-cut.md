# 施工斷面｜公式標準化不是排版清潔

狀態：保留／未閉合

這個斷面保存第八版公式系統從舊工作記號被收斂成正式規格時留下的改線痕跡。它不是要恢復多套正式公式，而是防止後來的「統一」把前面的施工史抹掉。

## 已確認的改線節點

提交：`f0e4b599c2a17d9f2ac3f8f1ec4c8ac04775c29c`  
提交訊息：`Standardize V8 formula rendering`

這次施工在 reader 的 `normalizeLegacyFormula()` 中明確加入了多種舊式輸入的自動收斂規則，其中包括：

- `S = NOT S` → `S = ～S`
- `S = ~S` → `S = ～S`
- 中文／英文實詞的刪線式 `X = X̸` → `X = ～X`
- `福德 = 福̸德̸` → `福德 = ～福德`
- `入流 = 入̸流̸` → `入流 = ～入流`
- 舊 LaTeX 分式、`barred`、斜線式與「非 X」等名稱層次記法 → `{{X}}`，再由 reader 生成上層「X」／下層 `～X` 的直式公式。

因此，現在的正式規格只有：

- 基本式：`S = ～S`
- 名稱層次：`{{S}}` → 上層「S」／下層 `～S`

但「舊寫法 → 正式寫法」本身就是第八版的一段施工，不准再被當成垃圾清走。

## 30260B 現場

初始封存節點 `fa5fe86379f3ef74934b4160f8fd2f0f68e44174` 的 30260B 中，已確認出現：

> 福德 = 福̸德̸

以及：

> 佛法 = 佛̸法̸

目前正文已收斂成 `～` 系統。這裡不把舊式重新冒充正式公式，而是把兩種狀態並排保存：

施工前：`福德 = 福̸德̸`  
施工後：`福德 = ～福德`

施工前：`佛法 = 佛̸法̸`  
施工後：`佛法 = ～佛法`

這個差異不是語義上的兩套理論，而是同一個公式機制在施工過程中更換了視覺語法。
