# 30350A｜公式規格改線斷面

這個斷面保留第十三分尾至第十四分單元 `30350A` 的公式施工改線。

## 初始封存斷面

基準：`fa5fe86379f3ef74934b4160f8fd2f0f68e44174`

當時單元頂部的工作規格是：

```text
F：S即非S，是名S。
```

這一版還沒有把公式拆成「基本式」與「名稱層次」兩套視覺／語義接口；它直接把《金剛經》句型當成單一施工公式。

## 現行斷面

目前 `main` 中同一位置改成：

```text
F：S = ～S；名稱層次 {{S}}。
```

也就是把原本一句話式的公式拆成兩條管線：

1. 基本式：`S = ～S`
2. 名稱層次：`{{S}}` renderer 接口

## 為什麼保留這個斷面

這不是單純排版更新。原先 `S即非S，是名S` 把「拆除」與「命名」壓在同一句裡；現行規格則把它們拆開，讓 `S = ～S` 處理拆除，`{{S}}` 處理「是名 S」的名稱層次。

因此這裡留下兩種施工語法並置：

- 舊線：`S即非S，是名S`
- 新線：`S = ～S` ＋ `{{S}}`

正式規格以新線為準；舊線不判定為錯誤，保留為第八版公式系統曾經如何從一句經文句型拆成兩個可重複接口的歷史鋼筋。

## 暫不處理

本單元正文仍大量使用「實相即非實相，是名實相」「第一波羅蜜即非第一波羅蜜，是名第一波羅蜜」等自然語句。這些不是要被 renderer 全面取代的髒資料；它們同時是正文與公式來源。暫不強制統一，以免把生成公式反過來蓋住文本本身。
