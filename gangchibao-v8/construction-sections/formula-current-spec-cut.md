# 《剛吃飽》第八版｜公式現行規格斷面｜2026-09-11

這不是清理舊公式，而是把目前已經存在於閱讀器與首頁的正式規格，和施工簿裡較早留下的規格敘述並置。

## 現行正式規格

- 中文：`S 即非 S，是名 S`
- 符號：`"S"/~S`
- 具名公式同理，例如：`"福德"/~福德`

其中 `~S` 對應「即非 S」，`"S"` 對應「是名 S」。

## 舊施工規格仍保留

施工簿早期斷面仍寫著：

- `S = ～S`
- 上層 `S`／下層 `～S` 的直式公式

這一段不刪、不改寫成不存在。它是公式系統曾經採用過的正式施工線；後來才再次改線成 `"S"/~S`。

因此後續巡檢採以下判斷：

1. 正文目前要被正式讀出的公式，以 `"S"/~S` 為準。
2. 明確屬於施工史、舊公式、工作語、斷面紀錄的 `S = ～S`、刪線式、`S barred`、`S ≠ S` 等全部保留。
3. 不為了視覺一致去重寫正文中可以辨認為施工痕跡的舊管線。
4. 如果同一位置同時出現新 renderer 與舊解說語，先判定它是不是版本改線留下的接口；高信心屬施工史者保留，不做語意清場。

## 目前接線狀態

`formula-scaffold.js` 已把正式閱讀層的 `S = ～S`、具名同名公式與 `{{...}}` renderer 輸出，校準成 `"S"/~S` 或對應具名形式；WORK／施工史與明確舊公式敘述被排除，不被覆寫。

首頁與 `reader-live.html` 也已使用現行規格。施工簿中的早期「正式規格」敘述因此不視為待刪錯字，而視為一個需要保留的歷史斷面。

這個文件本身就是鷹架：不清場，只標出哪一條現在通電、哪一條是舊管線。
