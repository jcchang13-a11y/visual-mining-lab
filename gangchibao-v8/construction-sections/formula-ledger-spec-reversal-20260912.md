# 第八版公式施工簿規格反轉斷面｜2026-09-12

狀態：高信心公式巡檢節點。此檔不回填、不清除施工簿舊宣告，只把目前已發生的規格反轉另外立一塊牌。

## 現況

`construction-ledger.md` 早期寫過：

- 「正式規格目前採」`S = ～S`
- 「正式讀法仍以」`S = ～S`「為準」
- 若干單元斷面也把 `S = ～S` 稱為現行／正式規格

這些句子現在已經不是現行規格，但它們不是要被刪掉的錯字。它們證明第八版曾經真的把 `S = ～S` 當作正式線路，後來才再次改線。

## 現行規格

目前新介面與新鷹架採：

- 中文：`S 即非 S，是名 S`
- 符號：`"S"/~S`

`S = ～S`、具名的 `X = ～X`、刪線式、`S barred`、`S ≠ S`、早期直式公式等，均保留為歷史施工斷面，不再被 LIVE reader 偷偷洗成新格式。

## 為什麼不直接改施工簿舊段落

因為那會把一次真正發生過的規格改線偽裝成「從來沒有改過」。爛尾樓版的規則不是讓所有說法最後一致，而是讓讀者能看見哪一段曾經被當成正式、哪一段後來又被撤回。

因此處理方式是：

1. 舊施工簿原句保留；
2. 首頁與 LIVE reader 繼續宣告目前規格；
3. 另立本斷面，說明施工簿內的 `S = ～S` 正式宣告已被後續規格覆蓋，但不抹除；
4. 後續公式巡檢以「新介面使用現行規格、歷史材料保留歷史表面」為驗收準則。

這不是清稿，是把規格反轉本身變成可閱讀的施工事故。
