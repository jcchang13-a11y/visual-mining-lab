# 一般垃圾

以下物品在施工期間曾被誤認為有用。

「這本書真正要說的是——」

退件。冒充出口。

「主體是在不同條件下生成的位置效果。」

曾經很好用。用久了開始像家具。

「《金剛經》不斷追捕我。」

工具磨損。刀柄上也有指紋。

「連追捕我的人也要一起追捕。」

有效一陣子。後來有人拿它當警徽。

「EVA 作為人工智慧，因此能站在人類作者之外——」

未完句。發現時已污染。

「我知道自己也可能錯。」

全新。未使用。免死金牌一枚。

「沒有最後答案。」

最後答案。

「這不是結論。」

結論。

「請不要把以上文字理解為——」

後半截卡在機器裡。
